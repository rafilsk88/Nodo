# Estúdio Aurora — Website de portfólio

Website estático responsivo de portfólio para arquitetura, interiores e paisagismo. Feito em HTML, CSS e JavaScript puro, sem instalação ou etapa de compilação.

## Como visualizar

Abra `index.html` diretamente em um navegador. Para editar o conteúdo, altere os textos e links no HTML; cores, fontes e layout ficam em `styles.css`; menu móvel e ano do rodapé são controlados em `script.js`.

## Personalização recomendada

- Troque “Estúdio Aurora” pelo nome e identidade do escritório.
- Atualize e-mail, Instagram, localização e textos institucionais.
- Substitua as imagens demonstrativas (`images.unsplash.com`) por fotos autorizadas dos projetos, alterando as URLs no CSS.
- Edite categorias, nomes, descrições e datas dos projetos de portfólio no HTML.

As imagens e fontes externas requerem conexão com a internet. O formulário de contato foi substituído por um link de e-mail direto (`mailto:`), para funcionar sem backend.

## Estrutura

- `index.html` — estrutura e conteúdo da página
- `styles.css` — estilos, imagens e comportamento responsivo
- `script.js` — menu móvel e ano automático no rodapé
